================================

Coloca aquí tus fotos (PNG con FONDO TRANSPARENTE recomendado) con
EXACTAMENTE estos nombres para que el sitio las use automáticamente:

1) tonny-hero.png
   - Foto principal del HERO (la de cuerpo sentado, manos juntas, camisa blanca).

   - Retrato (medio cuerpo) para la página "Sobre Tonny".

elegante como respaldo (no se rompe nada).
