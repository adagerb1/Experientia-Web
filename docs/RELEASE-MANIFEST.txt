CONTRATOS DE ESTABILIDAD 0.4
  - Una escritura pública solo confirma éxito con ID persistido.
  - La API no ejecuta DDL durante solicitudes HTTP.
  - Las migraciones se aplican por CLI y quedan en schema_migrations.
  - El cron procesa recordatorios y la cola de notificaciones.
  - OpenAI, WhatsApp, leads, pagos y oportunidades se conservan.

CONTRATOS COMERCIALES 0.6
  - AlexIA Comercial solo usa conocimiento aprobado y conserva toma humana.
  - Los canales aplican políticas de tipo, MIME, extensión y tamaño.
  - Campaña, oferta, clic, lead y pago mantienen una referencia trazable.
  - Purchase solo se registra después de un webhook de pago válido.
  - Las plantillas y los destinos CTA se resuelven desde el servidor.

ORDEN DE DESPLIEGUE
  1. Respaldo de archivos y base de datos.
  2. Publicar el código.
  3. php ops/cpanel/migrate.php
  4. php ops/cpanel/migrate.php --apply
  5. Crear o rotar el administrador con ops/cpanel/admin-user.php.
  6. Verificar GET /api/health y ejecutar el cron una vez.
  7. Confirmar schema_version=202608010001 y ejecutar el checklist de
     docs/commercial-launch.md antes de abrir pauta.
