RELEASE MANIFEST — Nucleus Growth Experience
============================================
Versión: 0.3.0
Stack:   Vue 3 (CDN/importmap, no-build) · PHP 8 API REST · MySQL (PDO)
Empaquetado: el ZIP NO debe contener carpeta raíz; descomprimir el
contenido interno directamente en public_html.

ESTRUCTURA ENTREGADA
  /index.html .htaccess robots.txt sitemap.xml llms.txt manifest.json
  /assets         (css modular + js + img/icons)
  /app            (componentes, vistas y datos del sitio público)
  /admin          (panel administrativo SPA)
  /api            (front controller + rutas)
  /core           (Controllers, Models, Services, Middlewares, Helpers, Http, Database, Db)
  /config         (app, database, payments, mail)
  /database       (schema.sql + seeds/seed.sql)
  /storage        (logs, exports, cache)
  /docs           (instalación, changelog, manifiesto)
